SUPER MARIO WORLD PARA PLAYSTATION 2
Retrogames Patos de Minas | v0.11 (beta) | NTSC 240p/480p | 4:3 ou 16:9 | Português

O QUE VOCÊ PRECISA

Um pendrive FAT32 e a sua própria cópia de Super Mario World (USA) de
SNES, em ZIP (com o .sfc/.smc dentro), .SFC ou .SMC. O pacote não inclui
o jogo. Um Memory Card formatado é necessário para gravar pela ISO.

O JEITO MAIS FÁCIL: GRAVADOR SMW PS2

Abra o arquivo Gravador_SMW_PS2.html no navegador do computador
(Windows, Linux ou Mac; não precisa instalar nada nem de internet). Ele
pede a sua cópia do jogo, confere se é a versão certa e grava tudo no
pendrive: o aplicativo (APPS/SMW), a ISO (pasta CD) ou os dois.

1. CARTUCHO: escolha ou arraste o .zip, .sfc ou .smc. A luz verde
   acende quando a cópia é a americana original; a laranja explica o
   que está errado (versão europeia/japonesa, hack, tradução...).
2. FORMATO: pendrive (aplicativo), lista de jogos (ISO) ou os dois.
3. AJUSTES: como o jogo abre (tela, vídeo e idioma), ou "perguntar".
4. DESTINO: escolha a raiz do pendrive (por exemplo E:\).
5. GRAVAR: grava e confere cada arquivo.

No Chrome e no Edge ele grava direto no pendrive, sem apagar o save que
já estiver lá. No Firefox e no Safari ele baixa um ZIP (ou a ISO): é só
descompactar na raiz do pendrive. A sua cópia do jogo não sai do
computador. A ISO e o SMW.ZIP gravados têm o seu jogo dentro: são só
para você.

JOGAR PELO PENDRIVE (SEM O GRAVADOR)

1. Pela lista de aplicativos (ELF)
   Copie a pasta APPS/SMW para dentro de APPS na raiz do pendrive e
   coloque nela a sua cópia com o nome "Super Mario World (USA).zip",
   SMW.ZIP, SMW.SFC ou SMW.SMC. Abra Aplicativos no OPL e selecione
   Super Mario World. Se o OPL não listar o aplicativo, execute
   mass:/APPS/SMW/SMW.ELF pelo wLaunchELF.

2. Pela lista de jogos do OPL (ISO)
   Gere a ISO com o Gravador (ou veja RECOMPILAR abaixo) e copie
   SMWG_000.01.Super Mario World.iso para a pasta CD do pendrive.
   No PS2, atualize a lista de jogos USB/BDM do OPL e abra o jogo.

Ao abrir, a tela mostra por 3 segundos onde o progresso será gravado
(pendrive, Memory Card 1 ou 2) e o estado de cada cartão.

CONTROLE

Direcional       mover e navegar
Cruz (X)         pular e confirmar
Quadrado         correr e carregar objetos
Círculo          salto giratório
Triângulo        segundo botão de corrida e de ação do SNES
Start            abrir o menu inicial ou pausar
Select           usar o item de reserva quando disponível
L1 e R1          deslocar a câmera nas fases que permitem

GRAVAR O PROGRESSO

Salve nos pontos oferecidos pelo próprio jogo. Ao gravar, aparece por 4
segundos no canto da tela onde ficou o save, por exemplo
"SALVO: MEMORY CARD 1".

- Pela ISO: no Memory Card, pasta SMWPS2 (cartão 1; sem ele, cartão 2).
  O pendrive fica só com o OPL, que o usa para ler a ISO.
- Pelo ELF: em APPS/SMW no pendrive. Se o pendrive recusar a gravação,
  o jogo grava no Memory Card e continua gravando lá.

Ao ligar, o jogo procura o save no pendrive e nos dois Memory Cards e
carrega a cópia mais recente, onde quer que ela esteja. A tela de
informações e o canto da tela no início do jogo mostram de onde veio:
- "CARREGADO: MEMORY CARD 1" (ou PENDRIVE / MEMORY CARD 2);
- "NENHUM SAVE: JOGO NOVO" quando não há save em lugar nenhum;
- "SAVE ILEGIVEL: VEJA LEIA-ME" quando existe save, mas nenhuma cópia
  pode ser lida ou todas estão corrompidas. A tela de informações diz
  qual arquivo falhou. Nesse caso o jogo começa vazio, mas NÃO apaga
  nada: antes de gravar por cima, o arquivo ruim é renomeado para
  SMW_S1.BAD (S = SMW.SRM, T = SMW.TMP, B = SMW.BAK).

Arquivos em cada lugar:
- SMW.SRM: o save atual (2.064 bytes: os 2.048 da SRAM do SNES, mais
  número da gravação e verificação CRC32).
- SMW.BAK: o save anterior. Só é substituído por um mais recente.
- SMW.TMP: cópia de segurança durante a gravação. Se o PS2 desligar no
  meio, deixe-o na pasta: o jogo recupera os dados ao abrir.
- SMW_*.BAD: arquivos ilegíveis ou corrompidos, guardados para análise.

Saves de versões anteriores (SMW.SRM e SMW.BAK de 2.048 bytes) continuam
sendo lidos. Entre eles, o jogo escolhe o que tem mais progresso (fases
concluídas e palácios). Na primeira gravação com esta versão, eles passam
para o formato novo, e o SMW.BAK fica com o melhor save antigo.

No navegador do PS2, a pasta SMWPS2 aparece como "Super Mario World /
PS2 Retrogames", com um ícone 3D de cartucho cinza escrito "SMW PS2". O
ícone é gravado depois do progresso, e só se sobrar espaço no cartão
(cerca de 60 KB): o save sempre tem prioridade.

CÓDIGOS DE "ERRO AO SALVAR"

A mensagem mostra um código de dois dígitos para cada local tentado,
por exemplo "ERRO AO SALVAR 14 24 31".

1º dígito: 1 = pendrive, 2 = Memory Card 1, 3 = Memory Card 2
2º dígito: 1 = sem cartão / local indisponível
           2 = cartão não formatado (formate no navegador do PS2)
           3 = cartão de PS1 (não serve)
           4 = falha ao gravar a cópia de segurança (SMW.TMP)
           5 = falha ao gravar o backup (SMW.BAK)
           6 = falha ao gravar o principal (SMW.SRM)
           7 = um arquivo ilegível não pôde ser preservado (.BAD); para
               não apagá-lo, esse lugar não foi usado
           8 = o driver do Memory Card não carregou
           9 = caminho de pasta inválido

Depois dos códigos pode vir o detalhe da última falha: "M" para o
Memory Card (ex.: "M2-4T") e "U" para o pendrive (ex.: "U25T"). O
primeiro número é a etapa (1 criar a pasta, 2 abrir para gravar,
3 gravar, 4 fechar, 5 abrir para ler, 6 ler, 7 conteúdo diferente), o
resto é o código devolvido pelo cartão ou pelo pendrive e a letra final
é o arquivo (T = SMW.TMP, S = SMW.SRM, B = SMW.BAK). "CHEIO" no fim =
o Memory Card está sem espaço (código -3).

"U27" = o pendrive recusou criar o arquivo. Causas comuns: pendrive
cheio, arquivo do save marcado como "somente leitura" no PC ou pendrive
em exFAT. Use um pendrive em FAT32 com espaço livre.

Se aparecer, anote a linha inteira. Ela diz exatamente o que corrigir.

VÍDEO E DESEMPENHO

Na tela de abertura, durante os 3 segundos com as informações:
- TRIÂNGULO: 480p, para adaptador HDMI ou cabo componente. Cada linha do
  SNES vira duas, com scanlines (visual de monitor de tubo/RGB).
- CÍRCULO, ou não apertar nada: 240p, para cabo AV (amarelo) e para
  adaptadores HDMI que não aceitarem 480p.
- Segurar QUADRADO: mostra de novo a tela FORMATO DA TELA (4:3 ou 16:9)
  depois da abertura.
IDIOMA: o jogo abre em português do Brasil. Para jogar em inglês, segure
SELECT nessa mesma tela de abertura (se o Gravador deixou o jogo em
inglês, SELECT volta para o português).

Se o Gravador deixou o vídeo em 480p, ele já entra em 480p sem apertar
nada; CÍRCULO volta para 240p.

Se escolher 480p e a TV ficar sem imagem, desligue e abra o jogo de
novo apertando CÍRCULO. No 480p, o PS2 deve estar com "Saída de vídeo
componente" em "Y Cb/Pb Cr" na Configuração do Sistema.

Durante o jogo (segurando L2 + R2):
- L2 + R2 + QUADRADO: liga/desliga as scanlines (no 480p).
- L2 + R2 + CÍRCULO: liga/desliga a suavização da imagem.
- L2 + R2 + CRUZ: troca entre 4:3 e 16:9 (a troca fica gravada junto
  com o próximo save).
- L2 + R2 + TRIÂNGULO: liga/desliga o medidor de desempenho, no canto
  de baixo. "TELA 60" = todos os 60 quadros de cada segundo foram
  desenhados; "TELA 30" = metade foi pulada para manter a velocidade.
  "DESENHO" é o tempo médio de um quadro desenhado e "LOGICA" o de um
  quadro pulado (só a lógica do jogo). Um quadro cabe em 16,7 ms.

O ritmo do jogo segue a atualização da TV, e o som se ajusta a ela sem
travar a imagem. Se um quadro demorar mais que o tempo de uma
atualização, o jogo avança até 2 quadros sem desenhar, para manter a
velocidade e a música corretas.

TELA 16:9 (BETA)

Na primeira vez que o jogo abre, depois da vinheta da Retrogames, vem a
tela FORMATO DA TELA: direcional escolhe 4:3 ou 16:9 e X confirma. A
escolha fica gravada (arquivo SMW.OPT, no mesmo lugar do save) e a tela
não aparece mais. O TESTE DA TV nessa tela tem um círculo que só fica
redondo quando a TV está no modo certo para a opção marcada.

Nas fases, o jogo mostra 43 colunas a mais de cada lado (342 em vez de
256): você vê mais da fase, sem esticar o desenho. O PS2 manda a imagem
no formato normal e a TV, no modo 16:9, abre ela para as proporções
certas. Com a TV em 4:3, a imagem fica espremida: troque o modo da TV
ou volte para 4:3 com L2 + R2 + CRUZ.

- Fases, salas de bônus, casas e castelos: tela larga.
- Título, menus, mapa e telas de transição: continuam em 4:3, com
  faixas pretas dos lados (o jogo não tem desenho além da borda nessas
  telas).
- Os inimigos e itens continuam surgindo e sumindo fora da área
  visível, como no 4:3: o jogo passa a carregar os objetos mais longe.
- No fim de algumas salas (por exemplo o telhado do castelo do Bowser) o
  cenário acaba antes da borda e o resto fica com a cor do fundo.
- Desenhar 342 colunas dá cerca de um terço a mais de trabalho. Se o
  medidor (L2 + R2 + TRIÂNGULO) mostrar "TELA 30" com frequência numa
  fase, conte para a gente qual foi.

AJUSTES DE ABERTURA (SMW.CFG E SMW.OPT)

O Gravador grava SMW.CFG junto do jogo (em APPS/SMW ou dentro da ISO),
um texto simples com o jeito de abrir:
  tela=perguntar   (ou 4:3, 16:9)
  video=perguntar  (ou 240p, 480p)
  idioma=pt        (ou en)
Dá para editar no Bloco de Notas. A tela escolhida no próprio PS2
(SMW.OPT, onde fica o save) vale mais que a do SMW.CFG. Sem esses
arquivos o jogo abre como antes: 240p, português, e pergunta a tela.

SOBRE ESTA VERSÃO

A lógica do jogo foi compilada em C para o Emotion Engine do PS2. Os
gráficos, mapas e sons vêm da cópia americana de SNES fornecida por
você. O carregador confere o CRC32 B19ED489 e aceita cabeçalho de
copiador de 512 bytes. Se houver um arquivo inválido na pasta, o jogo
continua procurando os outros nomes antes de mostrar o erro.

Mudanças da v0.11 (beta):
- Gravador SMW PS2 (Gravador_SMW_PS2.html): programa no navegador que
  confere a sua cópia e grava o aplicativo, a ISO ou os dois no pendrive
  (veja O JEITO MAIS FÁCIL, no começo).
- Tela FORMATO DA TELA na primeira vez, com o teste do círculo, em vez
  de apertar QUADRADO na abertura. A escolha fica gravada.
- SMW.CFG: o jogo pode abrir já em 16:9, 480p ou inglês (feito pelo
  Gravador). Os acentos aparecem nas telas novas da abertura.

Mudanças da v0.10 (beta):
- Tela 16:9 opcional: QUADRADO na abertura ou L2 + R2 + CRUZ durante o
  jogo (veja TELA 16:9 acima). Feita do zero neste port: o desenho da
  tela ganhou as colunas extras dos dois lados, e o jogo carrega
  cenário e objetos mais longe para não aparecerem nem sumirem à vista.
- Em 4:3 nada muda: a imagem é idêntica à da v0.9, quadro a quadro.

Mudanças da v0.9:
- Câmera do mapa: ao olhar em volta (START no mapa principal) e deslocar
  a vista 128 pixels ou mais, a câmera voltava para o lado errado e
  ficava parada longe do Mario, com o mapa travado. Agora volta certo.
- Castelo do Bowser (Porta da Frente): os desenhos em losango de uma das
  salas apareciam com peças erradas. O C só tinha 1 das 4 variantes
  desse objeto; agora as 4 vêm do cartucho.
- Outras 7 leituras além do fim de tabelas do motor (entrada em cano
  vertical, pose $46 do Mario, Cheep-Cheep vertical, memória de sprites
  $12, rolagem da camada 2, caminhos do mapa e blocos nas salas de
  Mode 7) agora leem os bytes certos do cartucho. Antes funcionavam por
  sorte da arrumação da memória.
- Desenho da tela (PPU) mais rápido, vindo de outro port de SMW para
  PS2 (veja CREDITOS.md). Testado quadro a quadro: a imagem é idêntica
  à da PPU anterior em 116.400 quadros (235 salas, português e inglês).
- Som: o volume do áudio do jogo no PS2 saía pela metade (cerca de
  -6 dB) por um ajuste do audsrv. Agora sai no volume cheio.
- Medidor de desempenho: L2 + R2 + TRIÂNGULO (veja acima).

Mudanças da v0.8:
- Corrige o progresso perdido ao reiniciar (ex.: Palácio Amarelo salvo
  e "progresso 0" ao ligar de novo). Com o pendrive recusando gravar, o
  save ia para o Memory Card sem erro, mas ao ligar o jogo carregava
  primeiro o save antigo do pendrive. Ao escolher o arquivo na tela
  inicial, esse save antigo era gravado por cima do bom no cartão (que
  ficava só no SMW.BAK).
- Ao ligar, carrega a cópia mais recente entre pendrive, Memory Card 1
  e Memory Card 2. Cada save leva um número de gravação e CRC32.
- Saves antigos continuam sendo lidos; entre eles, vale o que tem mais
  progresso. Quem foi afetado pelo problema acima recupera o save do

- Mostra na tela de onde o progresso foi carregado e onde foi salvo, e
  diferencia "nenhum save" de "save ilegível/corrompido".
- Arquivos ilegíveis ou corrompidos são renomeados .BAD, nunca

- O ícone do Memory Card é gravado depois do progresso e só se houver

RECOMPILAR

Use o pacote ps2dev v2.0.0 para Linux ou WSL. Substitua /opt/ps2dev
pelo seu caminho e execute em um terminal Bash, na pasta extraída:

  export PS2DEV=/opt/ps2dev
  export PS2SDK="$PS2DEV/ps2sdk"
  export GSKIT="$PS2DEV/gsKit"
  export PATH="$PS2DEV/bin:$PS2DEV/ee/bin:$PS2DEV/iop/bin:$PS2SDK/bin:$PATH"
  make -C Fonte -j4

O resultado fica em APPS/SMW/SMW.ELF. O módulo de som (audsrv) é
compilado da pasta Fonte/audsrv junto com o resto. Para gerar a ISO, coloque a sua
cópia em APPS/SMW/Super Mario World (USA).zip e use Python 3.8 ou
superior com pycdlib instalado:

  python3 Fonte/gerar_iso.py

O Gravador (Gravador_SMW_PS2.html) é gerado do código em Gravador/, com
o SMW.ELF já compilado dentro (não usa a ROM):

  python3 Gravador/gerar_gravador.py

O motor parte de snesrev/smw, revisão bd80629bc968267239c4a2fb77fa96d0ed62da7b.
